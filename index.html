Panduan Publis ke GitHub Pages (Public Link)

Ikuti langkah mudah berikut agar dashboard dapat diakses siapapun via link

1. Simpan Kode Ini

Simpan seluruh kode HTML di halaman ini dengan nama file index.html di komputer Anda.

2. Buat Repository di GitHub

  • Buka akun GitHub.com Anda.
  • Klik tombol New Repository.
  • Beri nama repository (contoh: packing-line3-dashboard).
  • Pilih opsi Public.
  • Centang "Add a README file" lalu klik Create repository.

3. Upload File index.html

  • Di dalam repository yang baru dibuat, klik tombol Add file → Upload files.
  • Drag and drop file index.html Anda.
  • Klik tombol hijau Commit changes.

4. Aktifkan GitHub Pages

  • Masuk ke menu Settings di repository Anda.
  • Klik tab Pages pada sidebar sebelah kiri.
  • Di bawah Build and deployment > Branch, ubah pilihan dari None menjadi main (atau master) dan folder /(root).
  • Klik Save.

Selesai!

Dalam 1-2 menit, link publik dashboard Anda akan muncul di bagian atas halaman Settings Pages, contoh: https://username.github.io/packing-line3-dashboard/
